# User Tutorial: EraIn Onboarding and Pilot Flow

## Who this is for
Founders, CXOs, and operations leaders using EraIn from first intake through execution governance.

## Step-by-step
1. Submit context via `/request-assessment`.
2. Save your request ID (`AR-...`) for follow-ups and client login access.
3. Review sample report structure and baseline findings.
4. Join qualification call and confirm one measurable objective.
5. Receive 21-Day Decision Governance Pilot proposal.
6. Align owners and cadence for D1-D21 execution windows.
7. Review readout, governance map, and ROI attribution pack.
8. Approve publication mode for proof asset: named or anonymized.

## What to prepare before kickoff
- Current KPI baseline
- Known leakage areas
- Decision owners by function
- Any existing operating cadence

## What success looks like
- Clear owner-path governance
- Faster decision loops
- Measurable impact trajectory
- Traceable evidence for leadership and references
