# EraIn Agentic AI Architecture

EraIn AI uses controlled, role-based agentic AI.

Core principles:
- Human-in-the-loop
- Explainable decisions
- Audit-ready outputs
- ROI accountability

Core Agents:
1. Data Validation Agent
2. Operations Analysis Agent
3. Insight Generation Agent
4. Decision Simulation Agent
5. Impact & ROI Agent

All actions are logged, scored, and reviewable.
