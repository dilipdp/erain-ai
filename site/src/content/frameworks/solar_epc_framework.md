# Solar & EPC Project Execution Framework™

EraIn’s Solar & EPC framework is built to **stop schedule slip, margin leakage, and commissioning risk** across rooftop and ground-mount projects.
It installs a **repeatable operating cadence** from pre-sales to O&M, with **proof-grade audit trails** that leadership can trust.

> **Outcome promise:** faster execution, fewer surprises, provable ROI, and permanent control loops.

---

## 1) Who this framework is for

This framework applies wherever solar/EPC execution is real-world and multi-actor:

- **Rooftop C&I**: 50 kW → multi‑MW, multi-building, multi-meter
- **Ground-mount / utility-scale**: BOQ, civil + electrical coordination, grid compliance
- **Hybrid**: storage, DG sync, backup modes, critical loads
- **O&M**: performance, warranty, spares, tickets, uptime governance

It works even when current data is messy:
- Excel estimates, WhatsApp approvals, manual site logs, mixed vendor invoices

## 4) Solar/EPC failure modes EraIn fixes

### 4.1 Commercial & estimation leakage
- BOQ/BOQ mismatch (design vs purchase vs site reality)
- Underestimated civil/structure work (reinforcement, waterproofing risk)
- HT/LT scope creep and approvals surprise
- Installation productivity assumptions not matching site constraints

### 4.2 Schedule slip & coordination
- Multi-vendor handoff breaks (civil ↔ electrical ↔ commissioning)
- Missing dependencies (materials, approvals, shutdown windows)
- No milestone proof → “done” claims without evidence

### 4.3 Quality, safety, compliance risk
- Earthing, lightning, terminations, torque control, crimping defects
- CEIG/DISCOM/process gaps, missing test certificates
- Commissioning failures due to incomplete punch list

### 4.4 O&M and performance decay
- PR degradation undetected (soiling, shading changes, inverter issues)
- Ticket loops without root cause
- Spares and warranty claims unmanaged

## 5) Scope map (end-to-end)

### 5.1 Pre‑sales / Discovery
- Site qualification checklist
- Load profile and savings logic
- Roof suitability and constraints
- Risk scoring (technical + commercial + compliance)

### 5.2 Survey → Design freeze
- Survey verification pack (photos, measurements, constraints)
- Sizing assumptions: DC/AC ratio, target offset, roof utilization
- SLD and layout freeze + sign-off gate
- BOM/BOQ and procurement alignment

### 5.3 Procurement & vendor governance
- Vendor scorecard: lead time, quality, warranty, replacement SLA
- PO discipline: spec lock, tolerances, acceptance criteria
- GRN + QC: evidence-based checks

### 5.4 Execution (site)
- Daily/weekly plan, manpower plan, material readiness
- Quality gates: structure, cabling, terminations, earthing, insulation
- Safety gates: work-at-height, LOTO, PPE compliance
- Punch list: evidence required to close

### 5.5 Commissioning & handover
- Pre‑commissioning checklist
- Test certificates, protection settings, metering verification
- Grid sync approvals / documentation
- Handover pack: as‑built, warranties, O&M playbook

### 5.6 O&M (ongoing)
- PR monitoring, inverter health, string issues
- Cleaning cadence optimization
- Ticketing + RCAs
- Spares governance

## 6) Data & document readiness (what we collect *later*)

You said you will **not collect documents until you’re ready**. This section defines the **minimum** and **ideal** data packs so the moment you decide, you can request cleanly.

### Minimum Pack (works even for small clients)
- Last 3 months: electricity bills (or meter readings)
- Project scope and site address / layout photos
- Existing BOQ/BOM (even rough)
- Vendor list + contact points
- Current schedule/milestones (even WhatsApp)

### Ideal Pack (for large client / multi-site)
- BOQ/BOM + drawings (SLD, layout, GA)
- Procurement: PO/GRN/QC logs
- Project logs: daily progress reports, punch lists
- Compliance docs: CEIG/DISCOM, test certificates
- O&M: generation logs, PR, tickets, warranty claims

> **EraIn rule:** we never ask for “everything.” We ask for **the smallest set** that unlocks verified truth.
