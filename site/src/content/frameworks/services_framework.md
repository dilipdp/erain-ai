# EraIn Services Framework™

**Goal:** turn a services business into a *measurable execution system*.
We diagnose the reality, quantify leakage, assign owners, install cadence, and prove impact.

**Applies to:** IT/ITES, agencies, consulting, B2B service delivery, maintenance/field services, support centers, shared services, backoffice operations.

**Operating Loop:** **Truth → Decisions → Execution → Impact**

---

## 0) What success looks like (non‑negotiables)

**Within 30 days (minimum):**
- Delivery visibility that teams actually use (not vanity dashboards)
- Weekly operating cadence with owners + checkpoints
- Top 5 leakages identified with **₹ impact ranges**
- At least **2 recovery actions shipped** and verified

**Within 90 days (typical):**
- Stable throughput, fewer escalations, fewer surprises
- Reduced rework / faster cycle time
- Clear accountability per client/project
- Verified ROI attribution (what changed, why, and how it sustains)

---

## 1) Common failure modes in services (what we hunt)

### Margin leaks
- Under-scoped work, change requests unmanaged, write‑offs
- Over-delivery / gold‑plating
- Unbilled effort, weak timesheet discipline
- Low utilization + noisy staffing

### Execution leaks
- Handoff failures, unclear ownership, weak escalation
- Rework loops (QA, client feedback, miscommunication)
- Inconsistent SOPs across teams/projects
- Tool sprawl: work scattered across chat + sheets + tickets

### Decision fog
- Late signals: leadership sees issues when it’s already costly
- Metrics without actions (no owner, no checkpoint)
- Client risk not quantified (renewal/churn probability unknown)

## 2) The EraIn engagement sequence

### A) EraIn Audit AI™ (Free entry audit)
**Purpose:** establish factual baseline.

**Outputs (always):**
- Ranked leak list (by urgency + likely impact)
- 30/60/90 roadmap
- Executive‑ready PDF summary

**Fast evidence we use:**
- Sample project plan / tracker (even if messy)
- 1–2 weeks of time + task data (can be partial)

- Org/roles + key clients

**Adds:**

- Risk register: delivery, churn, compliance, cashflow

**Deliverables (standard pack):**
- Exec deck + audit appendix
- Action register (owner, due date, checkpoint, status)
- KPI dictionary (definitions, sources, update cadence)
- Cadence calendar (weekly ops + monthly leadership)

## 3) Service business KPI map (what we measure)

### Delivery
- On-time delivery rate (per milestone)
- Cycle time (request → delivery)
- Escalation rate + aging
- SLA breach rate (where applicable)

### Quality
- Rework % (by cause)
- Defect leakage / client feedback loop time
- First-time-right %

### Commercial
- Gross margin by client / project
- Write-offs + unbilled effort
- Change request conversion %
- Cash collection cycle (DSO)

### People
- Utilization (billable vs non-billable)
- Capacity vs demand mismatch
- Context switching index (projects per person)

### Customer
- Renewal risk score / churn drivers
- NPS/CSAT drivers tied to actions
- Response time + resolution time

**Rule:** no metric is allowed to exist without an **owner** and a **next action**.

## 4) Data readiness (what we collect *only when ready*)

### Minimum safe set (Week 1)
- Client list + project list + owners
- Simple time data (even if partial)
- Billing model/pricing + recent invoices
- Work tracker export (Jira/Asana/Trello/Sheets)

### Preferred set (Week 2–3)
- Ticket/work logs with timestamps
- Change request records
- Delivery plan + milestones
- QA/defect logs (if relevant)

### Optional (later)
- CRM pipeline + churn history
- Call/email metadata (not content) for response-time mapping
- Finance exports for cost-to-serve

**Privacy guardrails:**
- Start with samples + redacted extracts.
- No raw sensitive docs until the audit pipeline is stable.
- Least access principle: only what’s needed, for the shortest time.

## 5) The 90-day execution plan (template)

### Week 1–2: Truth & Baseline
- Map workflow: request → delivery → billing → support
- Identify bottlenecks + top leakage categories
- Define KPI dictionary + owner map

### Week 3–6: Decisions & Control
- Install action register (owners + checkpoints)
- Fix the “Top 2” leakage sources
- Establish weekly ops review cadence

### Week 7–12: Execution & Impact
- Expand fixes across teams
- Add early warning alerts
- Publish ROI proof artifacts (leadership-ready)

---

## 6) Operating cadence (non‑negotiable)

### Weekly (60 minutes)
- What changed since last week?
- Top risks (next 7–14 days)
- Action register status (owners + dates)
- Decisions required (leadership approvals)

### Monthly (60–90 minutes)
- Portfolio view: margin, delivery, risk
- What improved and why (proof)
- What to stop doing
- Next month priorities

---

## 7) Roles & responsibilities

### Client side
- **Sponsor (CEO/COO/Founder):** clears decisions fast

- **Delivery leads:** own execution actions

### EraIn side
- **Audit Lead:** builds baseline + findings
- **Execution Lead:** installs cadence + accountability
