# Audit Delivery SOP (Outcomes, Not Effort)

Delivery stages:

1. Intake validation (day 0-1)
2. Baseline and leakage map (day 1-3)
3. Decision governance mapping (day 3-5)
4. ROI attribution model (day 5-7)
5. Executive readout and action owners (day 7-10)

Non-negotiables:

- Every recommendation must map to owner + cadence + expected KPI effect.
- Every KPI target must include baseline, target, and attribution logic.
- No recommendation without evidence source reference.

Definition of done:

- Auditability: source-linked findings complete
- Governance: decision owner and approval rule defined
- ROI: attribution logic and payback window defined
