# 1. PURPOSE

This Access Control Matrix defines who can access what data within EraIn AI engagements.

Objective:
• Protect client confidentiality  
• Enforce least-privilege access  
• Ensure traceability  
• Prevent unauthorized data exposure  

---

# 2. ACCESS ROLES

## Role A – Founder
Full oversight access across all engagements.
Responsibilities:
• Governance supervision  
• Legal compliance  
• Final report approval  

## Role B – Engagement Lead
Assigned per client.
Responsibilities:
• Data analysis  
• Model building  
• Report drafting  

## Role C – Analyst / Associate
Limited to assigned datasets.
Responsibilities:
• Data processing  
• KPI modeling  
• Documentation support  

## Role D – Viewer (Restricted)
Read-only access to final outputs only.
Responsibilities:
• Executive review  
• Decision participation  

---

# 3. DATA ACCESS MATRIX

| Data Category | Founder | Engagement Lead | Analyst | Viewer |
|--------------|----------|-----------------|----------|--------|
| Raw Client Data | Full | Full | Limited | None |
| Processed Data | Full | Full | Full | None |
| Financial Sensitive | Full | Limited | None | None |
| Restricted (Payroll / Bank) | Full | Case-by-case | None | None |
| Audit Outputs | Full | Full | Limited | Read-only |
| Final Reports | Full | Full | Read-only | Read-only |
| Risk Register | Full | Full | Limited | None |
| Legal Documents | Full | None | None | None |

Definitions:
• Full = Read + Write + Modify  
• Limited = Restricted to assigned scope  
• Read-only = View only, no edits  
• None = No access  

---

# 4. ACCESS CONTROL RULES

1. Access must be granted formally before data is shared.  
2. Access must be revoked immediately after engagement closure.  
3. No shared credentials allowed.  
4. No client data may be downloaded to unsecured devices.  
5. Access logs must be retained for audit defense.  

---

# 5. RESTRICTED DATA PROTOCOL

For Level 4 – Restricted Data:

• Explicit Founder approval required  
• Access time-bound  
• Access logged  
• No external storage  
• No local downloads unless encrypted  

---

# 6. ACCESS REVIEW CYCLE

Quarterly Review:

✔ Validate active access list  
✔ Remove inactive users  
✔ Confirm role alignment  
✔ Update engagement access map  

Founder must approve review sign-off.

---

# 7. INCIDENT RESPONSE

If unauthorized access is detected:

1. Immediate access suspension  
2. Incident logging  
3. Root cause investigation  
4. Client notification (if applicable)  
5. Remediation action plan
