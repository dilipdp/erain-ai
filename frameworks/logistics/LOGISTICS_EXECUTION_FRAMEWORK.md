## 0) What this is

This framework is the **standard operating system** EraIn uses to diagnose, fix, and continuously improve logistics and supply-chain operations.

It is designed for:
- **Small operators** (single warehouse / fleet / city)
- **Mid-market** (multi-city distribution, 3PL, multiple clients)
- **Enterprise** (multi-site, multi-carrier, multi-SKU, high compliance)

**We do not collect documents until your system is ready** (access control, scope lock, privacy terms, evidence standards).

## 1) Engagement sequence (non-negotiable)

### Phase A — Truth (Audit AI™)
**Goal:** Establish verified reality.
- What is happening vs what reports claim
- Where time/money/service is leaking
- What is measurable immediately

### Phase B — Decisions (Pro Audit™)
**Goal:** Quantify impact and choose the smallest set of highest leverage actions.
- Root-cause map for top leakages
- ₹/$ impact estimate + recovery potential
- Owners + cadence + checkpoints

### Phase C — Execution (OpsMind™)
**Goal:** Operate the cadence until outcomes stabilize.
- Weekly operating rhythm
- Exception management + escalation
- Evidence-based progress

### Phase D — Impact (Impact AI™)
**Goal:** Long-term ROI attribution and compounding improvement.
- Proof trails
- Controls + governance
- Multi-site standardization

## 2) Outcomes we deliver (logistics-specific)

### Cost outcomes
- Reduce **cost-to-serve** (per shipment / per kg / per km / per order)
- Reduce **empty miles** and under-utilization
- Reduce **detention/demurrage**, penalty leakages, expedite spend
- Improve **inventory carrying cost** via flow + slotting + replenishment discipline

### Service outcomes
- Improve **OTIF / SLA adherence**
- Reduce **damages, claims, returns**
- Improve **scan compliance** and shipment visibility
- Reduce **exceptions** (missed pickups, failed deliveries, misroutes)

### Speed outcomes
- Reduce **dock-to-stock** and **order cycle time**
- Reduce **dispatch delays** and **yard congestion**

### Reliability outcomes
- Improve **forecast-to-plan** stability
- Reduce **variance** across lanes / hubs / shifts
- Standardize SOPs across sites

## 3) Scope map (what we audit)

We select the smallest scope that still reveals the truth.

### A) Transportation (fleet / carriers)
- Trip planning, routing, load planning
- Carrier performance, rate cards, lane economics
- Vehicle utilization, empty miles, detentions
- Fuel discipline, maintenance discipline, driver behavior

### B) Warehousing (fulfillment / DC)
- Inbound receiving, putaway, slotting
- Pick/pack/ship throughput and bottlenecks
- Cycle count discipline, shrinkage, damages
- Labor planning, shift adherence, productivity

### C) Order-to-cash / customer execution
- Promise accuracy (ETA, delivery windows)
- Failed delivery drivers, RTO/returns loop
- Exception management and comms discipline

### D) Inventory and planning
- Forecast error, replenishment policy
- Stockouts/overstocks, aging inventory
- Vendor/PO delays, inbound reliability

### E) Governance and controls
- Approvals, overrides, rate exceptions
- Claims management discipline
- Audit trails, evidence standards

## 4) Data readiness: what we can start with

We can start from **whatever exists today**:
- Excel trackers
- Tally / accounting extracts
- WMS/TMS exports
- GPS/fuel data exports
- WhatsApp/Email logs (structured sampling)

### Minimum viable data (MV Data Pack)
Provide **any one** of these for the Free Audit:
1. Last 30–90 days shipment register (date, origin, destination, weight/vol, promised date, delivered date, status)
2. Fleet trip log (km, fuel, loading time, unloading time, detention, driver)
3. Warehouse daily throughput (inbound receipts, orders shipped, backlog, labor hours)

**If you don’t have these, we generate them in Week 1** using sampling + on-ground observation + lightweight templates.

## 5) EraIn measurement model (standard KPIs)

We measure what creates profit and reliability.

### Service KPIs
- **OTIF / SLA %** (by client, lane, hub)
- **Delivery promise accuracy** (ETA variance)
- **Scan compliance** (pickup, in-transit, delivery)
- **Exception rate** (failed delivery, misroute, damage)

### Cost KPIs
- **Cost-to-serve** (per shipment / per kg / per order)
- **Empty miles %** / utilization %
- **Detention/demurrage spend**
- **Expedite spend %**

### Speed KPIs
- **Order cycle time**
- **Dock-to-stock / dock-to-dispatch**
- **Yard/dock congestion time**

### Warehouse KPIs
- **Lines picked per labor hour**
- **Pick accuracy** / returns due to wrong pick
- **Inventory accuracy** / cycle count adherence

### Reliability KPIs
- Variance by shift/site
- Top recurring exception types
- Rework loops
