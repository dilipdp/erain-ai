

# EraIn AI — Data Intake Checklist (Audit-First Engagement)

**Purpose:**  
Ensure we collect only high-signal, decision-relevant data — without overwhelming clients or appearing unstructured.

We do NOT collect everything.  
We collect what is required to:
1. Identify value leakage  
2. Quantify impact  
3. Map root causes  
4. Build a 30/60/90 execution roadmap  

---

# 0. Before Collecting Anything (Mandatory Internal Check)

☐ Universal Execution Core finalized  
☐ Industry-specific diagnostic framework ready  
☐ KPI Library aligned to client type  
☐ Leakage Map categories selected  
☐ NDA template ready  
☐ Secure data storage folder created  

If any of the above is incomplete → DO NOT request client data.

---

# 1. Basic Company Context (All Clients)

Request:

- Company overview (1–3 page profile or website link)
- Org structure (high-level)
- Number of sites / plants / branches
- Revenue range (approximate is fine)
- Headcount
- Major products / services
- Key customer segments
- ERP / systems used (Excel, Tally, SAP, Zoho, custom, etc.)

Goal:
Understand structure before touching numbers.

---

# 2. Financial Snapshot (Last 12 Months)

Request:

- P&L (monthly if available)
- Revenue by segment (if available)
- Major cost buckets
- Working capital overview (if available)
- Top 10 expense categories

We DO NOT ask for:
- Bank statements
- Sensitive salary data
- Unnecessary personal data

Goal:
Identify margin leakage zones.

---

# 3. Operational Data (Industry Specific)

## Manufacturing / Industrial

- Production volume (monthly)
- Downtime logs
- Scrap / rejection rate
- OEE (if tracked)
- Maintenance logs
- Vendor list (top 20 suppliers)
- Procurement spend summary

---

## Logistics

- On-time delivery %
- Route performance
- Fuel cost trends
- Penalty / delay costs
- Warehouse throughput
- Vendor SLAs

---

## Services

- Utilization %
- Project overrun data
- Client churn rate
- Delivery timelines
- Effort estimation vs actual

---

## Solar / EPC

- Project timeline vs actual
- Site delay logs
- Cost overruns
- Vendor performance
- Inventory usage
- AMC performance (if applicable)

---

# 4. Process & Governance

Request:

- SOP documents (if any)
- Approval workflow structure
- Escalation matrix
- Internal audit reports (if available)
- Major recurring issues reported by leadership

Goal:
Identify ownership gaps and decision latency.

---

# 5. Qualitative Inputs (Leadership Interview)

We conduct structured interviews covering:

- Top 3 frustrations
- Biggest unknown risk
- Where money is leaking (in their view)
- Where decisions are slow
- What they wish they could measure but cannot

These are mandatory.

---

# 6. What We Explicitly Do NOT Ask Initially

- Raw customer personal data
- Detailed payroll records
- Sensitive compliance data (unless needed later)
- Full ERP dump
- Legal contracts (unless audit requires)

This builds trust.

---

# 7. Data Format Requirements

Preferred format:

- Excel (.xlsx)
- CSV
- PDF for reports
- No screenshots (unless unavoidable)

All files stored in:

/secure/client-name/intake-phase/

---

# 8. Intake Completion Criteria

Data intake phase is considered complete when:

☐ Financial snapshot available  
☐ Operational metrics for last 6–12 months available  
☐ Leadership interview completed  
☐ Top 5 suspected leakage zones identified  
☐ Initial impact hypothesis drafted  

Only then do we begin Audit AI analysis.
