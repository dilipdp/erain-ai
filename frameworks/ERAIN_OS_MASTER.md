# 3. THE ERAIN DIAGNOSTIC FLOW

Phase 1 — Reality Capture
- Collect raw process maps
- Extract KPI data (even messy Excel)
- Identify top 10 suspected leak zones
- Validate with leadership interviews

Phase 2 — Leak Quantification
- Estimate ₹/$ annual impact per leak
- Rank by impact × controllability
- Identify top 3 value-recovery targets

Phase 3 — Root Cause Mapping
- Symptom ≠ Cause
- Map process breakdown
- Identify ownership ambiguity
- Detect approval bottlenecks
- Trace data blind spots

Phase 4 — Execution Architecture
For each top leak:
- Define 1 accountable owner
- Define weekly measurable metric
- Define corrective action set
- Define 30/60/90 checkpoints

Phase 5 — Cadence Installation
- Weekly review
- KPI dashboard
- Exception alerting
- Escalation path
- Documentation of decisions

Phase 6 — ROI Attribution
- Before vs After metric comparison
- Financial recovery estimate
- Sustainability check
- Governance record

No step skipped.
No recommendation without owner.
