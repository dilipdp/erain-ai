

# SOLAR ROI CALCULATION MODEL
Version: 1.0  
Purpose: Standardize financial defensibility of EraIn Solar engagements  
Classification: Internal – Financial Governance Critical  

---

# CORE PRINCIPLE

Solar ROI must be:

✔ Weather-normalized  
✔ Tariff-validated  
✔ Double-count protected  
✔ Conservative-first  
✔ Finance reconcilable  

If PR improvement is not weather-adjusted → it is not defensible.

If revenue attribution does not match invoices → it is not reportable.

---

# 1 — ROI STRUCTURE

Total Recoverable Value (TRV) =
Σ (Controllable Loss × Recovery % × Time Window)

Net Recovered Value (NRV) =
Validated Financial Gain – Engagement Cost

ROI Multiple =
NRV / Engagement Cost

Payback Period =
Engagement Cost / Monthly Validated Gain

---

# 2 — WEATHER NORMALIZATION MODEL

Before calculating PR-based recovery:

Step 1:
Obtain actual irradiance (GHI/POA)

Step 2:
Calculate Expected Generation under actual weather

Weather-Normalized PR =
Actual Generation / (Installed Capacity × Irradiance)

Only controllable gap is monetizable.

Never monetize weather variance.

---

# 3 — PR RECOVERY MODEL

PR Gap (Controllable) =
Expected PR (Weather-Normalized Benchmark) – Actual PR

Generation Recovery Potential =
Installed Capacity × Irradiance × PR Gap

Financial Recovery =
Generation Recovery × Tariff

Recovery Range:
• Conservative: 40%
• Base: 60%
• Aggressive: 75%

Never assume 100% PR recovery.

---

# 4 — DOWNTIME MODEL

Downtime Financial Loss =
Average Hourly Generation × Downtime Hours × Tariff

Recoverable Portion =
Downtime Loss × Realistic Recovery %

Important:
If downtime already reflected in PR gap,
Do NOT double count.

Choose either:
• PR gap method
OR
• Downtime method

Never both for same loss.

---

# 5 — SOILING / CLEANING MODEL

Estimated Soiling Impact % × Annual Generation

Recoverable =
Soiling Impact × 50–70%

Only monetizable if:
Cleaning discipline is controllable.

Exclude:
Extreme dust storms or uncontrollable environmental events.

---

# 6 — GRID OUTAGE MODEL

Grid Outage Impact =
Generation Lost During Outage × Tariff

Recoverable only if:
• Internal protection coordination issue
• Transformer loading imbalance
• Synchronization delay under plant control

Pure DISCOM outages = Not recoverable.

Do not inflate.

---

# 7 — VENDOR SLA MODEL

Delayed Fault Response Loss =
Average Fault Downtime Excess × Hourly Generation × Tariff

Recovery Mechanism:
• SLA penalty
• Response time improvement
• Preventive spares stocking

Report separately:
• Revenue recovery
• Penalty recovery

---

# 8 — HT EXPORT LOSS MODEL

For HT plants:

Energy Generated ≠ Energy Exported

Loss Sources:
• Transformer loss
• Line loss
• Protection trips
• Metering mismatch

Financial Impact =
(Generated – Exported) × Tariff

Recoverable portion only if:
Loss above engineering benchmark.

---

# 9 — CASH vs P&L DISTINCTION

Solar ROI must separate:

1. Revenue gain (P&L impact)
2. Cash flow improvement
3. Working capital impact
4. Penalty avoidance

Never mix categories in single ROI claim.

---

# 10 — CONSERVATIVE PRESENTATION RULE

External presentation must:

• Show Conservative Case first
• Explicitly list assumptions
• Declare non-controllable exclusions
• Disclose risks

Target ROI Range:
3x–6x realistic for solar.

If projection >10x → stress-test.

---

# 11 — DOUBLE COUNT PROTECTION CHECK

Before reporting ROI:

[ ] PR and Downtime not counted together  
[ ] Soiling not double counted under PR  
[ ] Grid outage excluded if external  
[ ] No stacking of theoretical improvements  
[ ] Recovery % realistic  

If overlap detected → reduce claim.

Credibility > size of number.

---

# 12 — CFO DEFENSE CHECKLIST

[ ] Tariff validated from invoice  
[ ] SCADA data validated  
[ ] Irradiance normalization applied  
[ ] Financial reconciliation done  
[ ] Conservative case shown  
[ ] Assumptions documented  

If any unchecked → do not present.

---

# 13 — ROI MATURITY SCALE

Level 1 – Estimated  
Level 2 – Weather-adjusted  
Level 3 – Finance reconciled  
Level 4 – Validated post-implementation  
Level 5 – Institutionalized monitoring  

EraIn target:
Reach Level 4 before case study publication.
