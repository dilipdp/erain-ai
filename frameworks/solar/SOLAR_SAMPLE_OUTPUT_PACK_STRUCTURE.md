# SOLAR SAMPLE OUTPUT PACK STRUCTURE
Version: 1.0  
Purpose: Define exactly what a Solar client receives after EraIn Audit  
Classification: External-Ready Deliverable Blueprint  

---

# CORE PRINCIPLE

Every Solar engagement must produce:

• Board-ready executive clarity  
• Finance-defensible numbers  
• Engineering-grounded diagnostics  
• Execution-ready roadmap  
• Measurable ROI proof  

No generic reports.
Only structured decision-grade artifacts.

---

# OUTPUT PACK COMPONENTS

The Solar Output Pack contains 5 controlled artifacts:

1. Executive Audit Deck (Board / CXO Level)
2. Financial Impact Summary (CFO Level)
3. Technical Diagnostic Report (Engineering Level)
4. Execution Roadmap (Operations Level)
5. Data Appendix + Audit Trail (Governance Level)

---

# 1 — EXECUTIVE AUDIT DECK STRUCTURE

Slide 1 — Title
• Client Name
• Plant Capacity
• Engagement Scope
• Date
• Confidentiality Notice

Slide 2 — Executive Summary
• Total Recoverable Value (Conservative Case)
• Base Case Estimate
• Payback Period
• Top 3 Leakage Drivers

Slide 3 — Current Performance Snapshot
• PR vs Benchmark
• Downtime %
• Generation vs Expected
• Export vs Generation (HT if applicable)

Slide 4 — Ranked Leakage Map
• PR Gap (Controllable)
• Downtime Loss
• Soiling Loss
• Grid / Protection Loss
• Vendor SLA Loss

Ranked by ₹ impact.

Slide 5 — Financial Summary
• Annual Recoverable Value
• 3-Year Cumulative Impact
• ROI Multiple
• Sensitivity Range

Slide 6 — Root Cause Map
Visual tree:
Leak → Technical Cause → Process Cause → Ownership Gap

Slide 7 — Risk Assessment
• Operational Risks
• Vendor Risks
• Grid Risks
• Governance Risks

Slide 8 — 30/60/90 Execution Plan
• Actions
• Owners
• Impact
• Milestones

Slide 9 — Governance Model
• Weekly cadence
• KPI dashboard
• Review frequency
• Escalation structure

Slide 10 — Conservative Case Statement
Explicit assumptions listed.

---

# 2 — FINANCIAL IMPACT SUMMARY (CFO PACK)

Section A — Tariff Validation
• Tariff source (invoice month reference)
• PPA / DISCOM rate
• Net vs gross clarity

Section B — Weather Normalization
• Irradiance source
• Adjustment logic
• PR recalculation

Section C — Loss Categorization
| Loss Type | Annual Impact | Recovery % | Recoverable Value |

Section D — Conservative / Base / Stress Case

Section E — Cash vs P&L Impact Separation

Section F — Double Count Check Declaration

Signed statement:
"This report excludes uncontrollable external losses."

• Transformer rating

Section 2 — Generation Analysis

• Seasonal deviation

Section 3 — Downtime Analysis

• Response time

Section 4 — Soiling & Cleaning Assessment
• Cleaning frequency
• Seasonal dust impact
• Estimated recoverable gain

• Preventive gap

• SCADA data integrity
• Alert discipline
• Protection coordination issues

# VISUAL DESIGN RULES

Deck must:

• Use clean financial formatting
• Avoid technical clutter on executive slides
• Show Conservative Case first
• Clearly separate controllable vs uncontrollable
• Include version + date on every page

No exaggerated graphics.
No marketing exaggeration.
Only disciplined clarity.

---

# CONFIDENCE TEST

Before sending to client:

[ ] CFO can defend numbers  
[ ] Engineer agrees with diagnosis  
[ ] Founder can explain logic without slide  
[ ] No double counting  
[ ] Conservative case realistic  

If any doubt → revise.
