• CUF (Capacity Utilization Factor)
• Specific Yield (kWh/kWp)
• Downtime (planned vs unplanned)
• Grid outage hours
• Inverter availability
• DC/AC ratio performance
• Degradation rate
• Cleaning frequency adherence
• Preventive maintenance compliance
• Reactive maintenance %

Financial Overlay KPIs:

• Revenue per kWh
• Tariff structure
• PPA realization
• Generation variance vs projection
• O&M cost per MW
• Penalty exposure (SLA / PPA)

---

# 3 — PR DEVIATION MODEL

PR Gap =
Expected PR – Actual PR

Generation Loss =
Installed Capacity × Irradiance × PR Gap

Financial Loss =
Generation Loss × Tariff Rate

Recovery Model:
PR improvement × realistic recovery %

Never assume theoretical maximum.
Account for weather-normalized baseline.

---

# 4 — DOWNTIME LEAKAGE MODEL

Downtime Categories:
• Inverter failure
• Grid outage
• Transformer failure
• String fault
• Cleaning delay
• SCADA malfunction

Unplanned Downtime Loss =
Installed Capacity × Irradiance × Downtime Hours × Tariff

Recoverable % depends on root cause.

---

# 5 — O&M DISCIPLINE MODEL

Evaluate:

• Preventive maintenance adherence
• Cleaning schedule compliance
• Fault response time
• Root cause tracking depth
• Spare part availability
• Vendor performance scoring

Maintenance Leakage =
(O&M inefficiency %) × Annual Revenue

Recovery potential typically 20–40%.

---

# 6 — FINANCIAL VARIANCE MODEL

Projected Generation vs Actual

Variance % =
(Actual – Projected) / Projected

Variance Causes:
• Weather variance
• Design error
• Soiling
• Shading
• Degradation
• Equipment mismatch
• Monitoring blind spots

Financial Attribution must isolate controllable vs uncontrollable factors.
