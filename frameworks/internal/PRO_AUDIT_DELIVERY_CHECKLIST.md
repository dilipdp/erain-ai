

# EraIn Pro Audit™ — Delivery Checklist
Version: v1.0
Owner: EraIn Core
Purpose: Ensure every Pro Audit is delivered at board-grade quality with zero fluff and measurable impact.

---

# 1. Pre-Engagement Discipline (Before Analysis Starts)

## 1.1 Scope Confirmation
- [ ] Client industry confirmed
- [ ] Revenue scale documented
- [ ] Primary objective clearly stated (margin recovery / cost reset / turnaround / scale)
- [ ] Decision-maker identified (CEO / COO / Owner)
- [ ] Engagement boundaries defined (sites, departments, timeframe)

## 1.2 Data Intake Readiness
- [ ] Data checklist sent
- [ ] NDA signed (if required)
- [ ] Data structure validated (no blind ingestion)
- [ ] Missing datasets identified and requested
- [ ] Data assumptions documented explicitly

---

# 2. Analysis Quality Control

## 2.1 Leakage Identification Standards
Every identified leakage must:
- [ ] Be observable in data
- [ ] Be tied to a measurable KPI
- [ ] Have quantified ₹ / $ impact
- [ ] Include root-cause hypothesis
- [ ] Avoid generic statements

If it cannot be measured, it cannot be included.

## 2.2 Financial Quantification
- [ ] Revenue impact estimated conservatively
- [ ] Cost impact estimated conservatively
- [ ] Assumptions explicitly stated
- [ ] No inflated ROI projections
- [ ] Sensitivity scenario (best / realistic / conservative) documented

---

# 3. Root Cause Discipline

Each Top 3 Issue must include:
- [ ] Symptom clearly described
- [ ] Root cause clearly isolated
- [ ] Systemic driver identified (process / ownership / incentives / tooling)
- [ ] Evidence from data
- [ ] Financial implication

Avoid “surface-level blame.”

---

# 4. 90-Day Execution Plan Validation

Each action in 90-day roadmap must:
- [ ] Have a named owner role
- [ ] Have measurable KPI target
- [ ] Have a deadline
- [ ] Have checkpoint frequency
- [ ] Have financial expectation

No vague actions allowed.

Bad example:
> Improve communication.

Good example:
> Reduce dispatch delay from 18h to 6h within 45 days (Ops Head accountable).

---

# 5. Board-Readiness Test

Before sending report:

- [ ] Would a CFO sign off on these numbers?
- [ ] Would a CEO present this to a board?
- [ ] Are assumptions defendable?
- [ ] Is language precise (no buzzwords)?
- [ ] Is impact ranked clearly?
- [ ] Is the executive summary under 2 pages?
- [ ] Does the narrative flow logically?

If not, revise.

---

# 6. Deliverables Verification

## Mandatory Output Artifacts
- [ ] Executive PDF (Board-ready)
- [ ] Financial Impact Sheet (Excel)
- [ ] Root Cause Map (visual)
- [ ] 30/60/90 Execution Tracker (Excel template)
- [ ] Alignment Call Agenda prepared

---

# 7. Alignment Call Readiness

Before presenting:
- [ ] Top 3 findings rehearsed
- [ ] Financial impact defendable live
- [ ] Objection responses prepared
- [ ] Upgrade pathway (OpsMind / Impact AI) mapped logically
- [ ] No hard sell — upgrade must feel inevitable

---

# 8. Upgrade Qualification Rule

Upgrade recommended only if:
- [ ] Impact > 5x monthly OpsMind fee
- [ ] Leadership commitment confirmed
- [ ] Execution owner identified
- [ ] Clear measurable ROI exists

If not, do NOT push upgrade.

Trust > short-term revenue.

---

# 9. Internal Post-Delivery Review

After submission:
- [ ] Internal review meeting done
- [ ] What was strong?
- [ ] What lacked precision?
- [ ] Which assumptions were weakest?
- [ ] Improvement documented in framework

Continuous improvement required.

---

# 10. Non-Negotiables

- No vanity dashboards.
- No AI hype language.
- No inflated ROI.
- No generic consulting language.
- No template laziness.
- No copy-paste across industries without adjustment.

Every Pro Audit must feel:
- Precise
- Calm
- Financially disciplined
- Operationally sharp
- Trustworthy

---

# Standard of Delivery

EraIn does not deliver “reports.”

EraIn delivers:
- Clarity
- Quantified truth
- Executable change
- Measurable impact

If it does not create executive confidence, it is not ready.
