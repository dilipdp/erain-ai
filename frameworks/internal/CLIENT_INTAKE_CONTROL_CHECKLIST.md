

# EraIn AI — Client Intake Control Checklist  
Version: 1.0  
Status: Controlled Intake Protocol  
Owner: Founder / Engagement Lead  

---

## ⚠️ Core Rule

**No client data is collected until:**
1. Scope is defined  
2. NDA is signed  
3. Engagement phase is confirmed (Free Audit / Pro Audit / OpsMind)  
4. Required data list is customized per industry  

This document prevents over-collection, under-collection, and trust erosion.

---

# Phase 0 — Pre‑Collection Readiness (Internal Only)

Before requesting any documents, confirm internally:

- [ ] Universal Execution Core finalized
- [ ] Industry framework selected (Manufacturing / Services / Logistics / Solar / etc.)
- [ ] Leakage Map template ready
- [ ] KPI Library ready
- [ ] Execution Tracker template ready
- [ ] ROI Attribution model ready
- [ ] Sample Output Pack ready (PDF structure defined)
- [ ] NDA template finalized
- [ ] Secure storage folder created

If any item is unchecked → **DO NOT collect client data yet.**

---

# Phase 1 — Engagement Classification

Select engagement type:

### ☐ Free Audit AI™  
Lightweight structured assessment  
High-level operational + financial clarity  
No deep financial extraction  

### ☐ Pro Audit™  
Deep-dive root cause  
₹/$ quantification  
90-day execution roadmap  

### ☐ OpsMind™  
Ongoing execution + monitoring  
Weekly cadence  
KPI automation  

---

# Phase 2 — NDA & Data Boundary Definition

Before document request:

- [ ] NDA signed
- [ ] Data retention period defined
- [ ] Access boundaries defined (read-only / shared folder / email)
- [ ] Sensitive exclusions defined (payroll names, personal data, trade secrets if not required)
- [ ] Single point of contact assigned

---

# Phase 3 — Minimum Data Requirement (By Industry)

⚠️ Never request “everything.”  
Request only what maps to leakage detection.

---

## A. Manufacturing / Industrial

Minimum Required:

- [ ] Last 6–12 months P&L
- [ ] Production output (monthly)
- [ ] Downtime log
- [ ] Maintenance log
- [ ] Scrap / rejection %
- [ ] Vendor purchase summary
- [ ] Workforce structure (role-wise count)
- [ ] Top 5 operational issues (leadership view)

Optional (Pro Audit level):

- Detailed cost breakdown
- Shift productivity data
- Inventory aging
- OEE data
- Capex plan

---

## B. Services (B2B / Consulting / Delivery)

Minimum Required:

- [ ] Revenue by client (last 6–12 months)
- [ ] Utilization %
- [ ] Project delivery delays
- [ ] Team structure
- [ ] Cost breakdown (major heads)
- [ ] Client churn / renewal data

Optional:

- Time-sheet exports
- Effort variance logs
- Pricing model

---

## C. Logistics / Supply Chain

Minimum Required:

- [ ] Shipment volume
- [ ] Delay %
- [ ] Penalty data
- [ ] Cost per route / per shipment
- [ ] Fuel & variable cost summary
- [ ] Vendor contracts (summary level)

Optional:

- GPS logs
- Warehouse throughput data
- SLA performance dashboard

---

## D. Solar / EPC

Minimum Required:

- [ ] Project list (completed + ongoing)
- [ ] Cost vs budget summary
- [ ] Commissioning delay log
- [ ] Vendor payment summary
- [ ] Procurement cycle time
- [ ] Service ticket log

Optional:

- Detailed BOM
- O&M performance
- Warranty claim history

---

# Phase 4 — Data Integrity Check

Before analysis begins:

- [ ] Files readable & complete
- [ ] Date range confirmed
- [ ] Units standardized (₹ / $, monthly)
- [ ] Obvious anomalies flagged
- [ ] Leadership assumptions documented

---

# Phase 5 — Intake Confirmation Document (Send to Client)

After receiving data, send confirmation:

- What data was received
- What will be analyzed
- What will NOT be analyzed
- Expected delivery timeline
- Next meeting date

This increases trust and prevents scope creep.

---

# Phase 6 — Data Security Protocol

- Store in encrypted folder
- Access limited to engagement lead
- No WhatsApp sharing
- No AI tools outside controlled environment
- Delete raw files after engagement (unless extended by agreement)

---

# Red Flags — Pause Collection If:

- Client sends disorganized dump without structure
- Client asks for AI before audit
- Client wants ROI guarantee before analysis
- Leadership unavailable for review call
- No decision-maker involved

---

# Intake Completion Gate

Intake phase is complete only when:

- [ ] Data validated
- [ ] Leakage Map drafted
- [ ] Preliminary KPI baseline created
- [ ] Initial hypothesis list prepared
- [ ] Delivery timeline locked

Only then move to Analysis Phase.

---

# Why This Document Exists

EraIn is audit-first, trust-first, execution-first.

We do not:
- Collect data casually
- Overpromise before quantification
- Run AI experiments without structure
- Allow scope drift

This checklist protects:
- Client trust
- Engagement clarity
- ROI credibility
- Long-term reputation
