

# EraIn AI — Delivery Artifacts Checklist

Version: 1.0  
Owner: EraIn Internal  
Applies to: Free Audit, Pro Audit, OpsMind™, Impact AI™

---

# 1. Client Folder Structure (MANDATORY)

Every client engagement must follow this exact structure:

```
/clients/
  /CLIENT_NAME/
    00_Admin/
    01_Intake/
    02_Data_Raw/
    03_Working/
    04_Analysis/
    05_Deliverables/
    06_Execution_Tracker/
    07_Communication/
    08_Archive/
```

No deviations. No creative folder naming.

---

# 2. File Naming Convention (STRICT)

Format:

```
CLIENTNAME_ARTIFACTTYPE_VERSION_DATE
```

Example:

```
ACME_PRO_AUDIT_REPORT_v1_2026-02-20.pdf
ACME_ROOT_CAUSE_MAP_v1_2026-02-20.pdf
ACME_90DAY_EXECUTION_PLAN_v1_2026-02-20.xlsx
ACME_EXECUTION_TRACKER_v1_2026-02-20.xlsx
```

Rules:
- No spaces in file names
- Dates always YYYY-MM-DD
- Version always explicit (v1, v2, v3)
- Never overwrite old versions — archive them

# 3. Free Audit — Required Deliverables

Folder: `05_Deliverables/Free_Audit/`

Required:

1. Executive Summary PDF
2. Ranked Findings Table
3. 30/60/90 Roadmap
4. Request ID Reference

“Done” means:
- Findings ranked by impact
- Clear problem → impact mapping
- Roadmap has owner placeholders
- PDF formatted executive-ready

---

# 4. Pro Audit — Required Deliverables

Folder: `05_Deliverables/Pro_Audit/`

Mandatory Artifacts:

1. Executive Report (PDF)
2. Root Cause Map (PDF or slide deck)
3. Impact Quantification Sheet (Excel)
4. 90-Day Execution Plan (Excel)
5. Executive Walkthrough Deck (PPT/PDF)
6. Alignment Call Notes (PDF)

“Done” means:
- Top 3 leaks quantified in ₹/$
- Root causes identified (not symptoms)
- Owners assigned
- Cadence defined
- Clear success metrics

No quantified impact → Not Done.

# 7. Execution Tracker Standard

Every client must have:

```
06_Execution_Tracker/
  CLIENT_EXECUTION_TRACKER_v1.xlsx
```

Columns required:
- Issue
- Root Cause
- Owner
- Deadline
- Status
- Financial Impact
- Verified?

No tracker → No discipline → No credibility.

---

# 8. Communication Log

Folder: `07_Communication/`

Maintain:
- Meeting notes
- Decisions made
- Action commitments
- Version history

Every major decision must be documented.

---

# 9. Definition of “Complete” (Non-Negotiable)

An engagement is complete only when:

1. Impact is quantified
2. Owners are assigned
3. Execution tracker exists
4. Deliverables archived properly
5. Version history maintained

If any of the above is missing → Engagement is incomplete.

---

# 10. Trust Rule

We do NOT collect client documents until:

- Folder structure is ready
- Templates are ready
- Execution tracker template is ready
- Naming convention understood
- Versioning discipline in place

We protect client trust through operational discipline.

---

# 11. Internal Review Gate (Before Sending Any Deliverable)

Checklist:

- Is impact quantified?
- Is root cause validated?
- Is language executive-level?
- Are visuals clean and minimal?
- Are file names correct?
- Is version number correct?

Only then send.

END OF CHECKLIST
