# PHASE 1 — PRE-DATA CLIENT ALIGNMENT (Day 6–7)

Goal: Structured expectations before document intake.

For each client:

1. Clarify Scope:
   - What problem do they THINK they have?
   - What problem do we suspect?
   - What outcome matters most (₹, time, compliance, throughput)?

2. Define Audit Boundaries:
   - Time period (last 6 months / 12 months)
   - Sites involved
   - Departments included

3. Confirm Data Types (but DO NOT collect yet):
   - Excel files
   - ERP exports
   - Tally
   - Production logs
   - Dispatch logs
   - Maintenance records
   - Financial P&L
   - Vendor ledgers

4. Sign NDA if required.

Only after this → move to Phase 2.

# PHASE 3 — AUDIT EXECUTION FLOW

Apply Universal Core:

3. Quantify impact
4. Root cause analysis
5. Owner assignment
6. 30/60/90 roadmap
7. Executive summary

Never skip sequence.

---

# PHASE 4 — EXECUTIVE REPORT

Every client gets:

### 1. Executive Summary (5–7 pages max)
- Top 5 findings
- ₹ impact estimate
- Top 3 root causes
- 90-day plan
- Risks of inaction

### 2. Detailed Audit (appendix)
- KPI breakdown
- Process maps
- Data validation
- Calculation logic

### 3. Leadership Call
- 60 min structured walkthrough
- Confirm ownership
- Confirm next step (Pro Audit / OpsMind)
