

# EraIn AI — Client Onboarding Sequence

## Purpose
This document defines the exact step-by-step onboarding protocol for every EraIn client.
No data is collected until readiness, scope clarity, and executive alignment are confirmed.

This protects:
- Client trust
- EraIn credibility
- Execution quality
- ROI attribution
- Long-term partnership value

---

# Phase 0 — Pre-Data Readiness (No Documents Yet)

## Step 0.1 — Executive Sponsor Confirmation
Must identify:
- Decision maker
- Budget authority
- Operational champion

Without these → onboarding does not proceed.

## Step 0.2 — Problem Clarity Call (60–90 min)
Objectives:
- What is breaking?
- Where is money leaking?
- What outcome matters in 90 days?
- What would success look like?

Output:
- One-page Problem Statement
- Defined 90-day success metric

## Step 0.3 — ROI Definition Agreement
Before data collection:
- Define financial baseline (approximate is fine)
- Define measurable KPI shift target
- Define ownership expectations

No ROI definition = no engagement.

---

# Phase 1 — Controlled Data Intake

Only after Phase 0 is signed off.

## Step 1.1 — Data Scope Confirmation
Client selects ONLY what is needed for audit.
Typical starting sources:
- Excel reports
- ERP exports
- Production logs
- Financial summary reports

We do NOT:
- Take full database dumps
- Request sensitive HR or payroll unless required
- Ask for anything unrelated to defined scope

## Step 1.2 — Data Responsibility Matrix
Client must assign:
- Data owner
- Clarification contact
- Timeline for access

Output:
- Data Intake Checklist (signed)

---

# Phase 2 — Audit Execution (7–14 Days)

## Step 2.1 — Baseline Establishment
We document:
- Current KPI levels
- Process flow map
- Identified leak categories

## Step 2.2 — Leakage Mapping
Categories evaluated:
- Financial leakage
- Time leakage
- Capacity leakage
- Decision latency
- Ownership gaps
- Compliance risk

## Step 2.3 — Quantified Impact Model
For top 3 leaks:
- Estimated loss
- Recovery potential
- Effort required
- Timeline

---

# Phase 3 — Executive Report Delivery

Deliverables:
1. Ranked Findings (by impact)
2. Root Cause Maps
3. 30/60/90 Execution Plan
4. Ownership Matrix
5. ROI Projection Model

Includes:
- Executive PDF
- Optional board deck
- Alignment call

No upsell pressure. Only evidence.

---

# Phase 4 — Upgrade Decision Gate

Client chooses:
- Stop (retain audit insights)
- Move to Pro Audit
- Deploy OpsMind
- Enterprise rollout

Decision is based on quantified clarity.

---

# Safeguards

EraIn never:
- Starts OpsMind without quantified audit
- Runs AI experiments without owners
- Promises ROI without measurement logic
- Collects excess data without purpose

---

# Standard Timeline (Typical)

Day 0–3: Alignment + readiness
Day 4–7: Data intake
Day 8–14: Audit + analysis
Day 15: Executive presentation

---

# Internal Checklist (EraIn Team)

Before starting any client:
- [ ] Sponsor confirmed
- [ ] ROI defined
- [ ] Data scope limited
- [ ] Success metric agreed
- [ ] Engagement scope documented

If any box is unchecked → pause onboarding.

# Principle
We do not collect data to "try AI." 
We collect data to prove business impact.

Onboarding discipline is what makes EraIn different from consulting firms and AI vendors.
