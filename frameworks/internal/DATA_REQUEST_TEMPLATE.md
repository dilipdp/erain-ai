# ERAIN AI — CONTROLLED DATA REQUEST & GOVERNANCE FRAMEWORK (V3.0)

**Purpose:**  
This document defines the controlled, minimal, and structured data requirements for EraIn audit and execution engagements.  
We collect only what is necessary for diagnostic accuracy and measurable impact mapping.

This document is client-shareable.

---

# CORE PRINCIPLE

EraIn collects data only to establish verified operational truth.

We do not collect data for exploration, experimentation, or vague analysis.  
Every data point requested must map to:

• A leakage hypothesis  
• A decision clarity objective  
• A measurable impact pathway  

If a data request cannot be tied to one of the above, it is not collected.

---

# 1. PRE-COLLECTION CONTROL GATE (MANDATORY)

No data is requested or collected until the following are completed:

☐ NDA signed  
☐ Engagement scope confirmed (Free Audit / Pro Audit / OpsMind / Impact AI)  
☐ Data Security Policy shared  
☐ Client Code assigned (for anonymized storage)  
☐ Data classification level agreed  

Additional Mandatory Controls:

☐ Defined objective for data use  
☐ Named internal data owner (client-side)  
☐ Defined data expiration date  
☐ Written confirmation of consent for sensitive tiers  

No collection proceeds without these confirmations.

If any box is unchecked → data collection does not begin.

---

# 2. DATA MINIMIZATION PRINCIPLE

EraIn follows:

- Collect only what is required to diagnose leakage or execution gaps  
- Prefer aggregated data over raw sensitive data  
- Prefer exports over live system access  
- Prefer supervised review sessions for highly sensitive material  

We do NOT request system logins unless explicitly required under enterprise scope.

---

# 3. UNIVERSAL CORE DATA (ALL INDUSTRIES)

Required for Free or Pro Audit.

## A. Financial Snapshot (6–12 Months)

Minimum Required:
- Monthly revenue
- Major cost categories
- Gross margin (if available)
- Top 5 expense heads
- Known exceptional losses (if any)

Preferred Format:
Excel / CSV / Structured ERP export

Not Required:
- Payroll-level breakdown
- Bank statements
- Personal financial data

---

## B. Operational Overview

- Org structure (high-level)
- Departments and ownership mapping
- Existing KPI sheet (if available)
- Top 5 recurring operational issues
- Any existing review cadence (weekly/monthly reviews)

---

## C. End-to-End Workflow Summary

Short written description of:
- How work moves from start to completion
- Key handoffs
- Approval points
- Escalation flow
- Bottlenecks (if known)

We accept written summaries if no formal documentation exists.

---

# 4. INDUSTRY-SPECIFIC EXTENSIONS (COLLECT ONLY IF APPLICABLE)

## Manufacturing / Industrial

- Monthly production volume
- Downtime logs (summary acceptable)
- Scrap / rejection %
- Maintenance cadence
- Shift structure
- OEE (if tracked)

---

## Logistics / Supply Chain

- Shipment volume
- On-time delivery %

---

---

## Solar / EPC / Project-Based

- Budget vs actual cost
- Vendor list (category-level acceptable)

- Site-level performance data (if applicable)

---

# 5. DATA CLASSIFICATION LEVELS

### Tier 1 — Aggregated / Non-Sensitive
KPIs, summarized reports, dashboards

### Tier 2 — Operationally Sensitive
Cost sheets, vendor names, internal workflows

### Tier 3 — Highly Sensitive
Payroll data, contracts, personal information, banking details

Tier 3 requires:
- Written client approval
- Explicit purpose definition
- Limited-time access window

---

# 6. WHAT ERAIN DOES NOT COLLECT

❌ Employee personal data unless absolutely required  
❌ Bank login credentials  
❌ Raw customer PII (unless legally necessary and approved)  
❌ Full ERP database dumps  
❌ Production system admin access (unless enterprise contract)  
❌ Source code (unless explicitly contracted)

---

# 7. DATA HANDLING & STORAGE PROTOCOL

- Stored in encrypted client-specific directory  
- Folder naming convention: CLIENTCODE_ENGAGEMENTTYPE_YYYYMMDD  
- All files version-tagged (v1, v2, FINAL)  
- Change log maintained for every data update  
- Labeled using Client Code (never company name)  
- Access restricted to assigned engagement members  
- No cross-client data exposure  
- Secure deletion post-retention window  
- Optional supervised review for Tier 3 data

Retention:
- Free Audit: 30 days
- Pro Audit: 90 days
- Enterprise: As per contract

---

# 8. DATA SUBMISSION METHODS

Preferred:
- Restricted shared drive
- Encrypted ZIP (password shared separately)
- Secure upload portal
- Supervised screen-sharing session

Not Recommended:
- WhatsApp documents
- Public Google Drive links
- Plain email attachments without encryption
