# EraIn AI™ — Data Intake Checklist (Client Version)
Version: 1.0
Classification: Confidential
Purpose: Structured, minimal, audit-safe data collection before audit execution

---

## 1. Purpose of This Document

This checklist defines the exact documents and data required to conduct:

- EraIn Audit AI™
- EraIn Pro Audit™
- OpsMind™ deployment preparation

We collect only what is necessary.
No uncontrolled data transfer.
No informal WhatsApp dumps.
No random email attachments.

All submissions must follow this structure.

---

## 2. Secure Submission Protocol

Before sending any data:

- Confirm NDA is signed (if applicable)
- Confirm official EraIn upload channel (Drive / Vault / SFTP)
- Do NOT send sensitive documents over email or messaging apps
- Use folder names exactly as defined below

Root Folder Format:

CLIENTNAME_YYYYMMDD_AUDIT

Example:
ABC_Manufacturing_20260220_AUDIT

---

## 3. Core Company Information (Mandatory)

Folder: 01_Company_Profile

Required:

- Company overview deck or profile (PDF)
- Org structure chart
- List of sites / plants / branches
- Key leadership contacts
- Revenue range (approximate acceptable)
- Number of employees
- ERP / Tally / Excel systems currently used

---

## 4. Financial & Performance Data

Folder: 02_Financials

For last 12 months (preferred):

- P&L summary (monthly if available)
- Revenue breakdown by segment / plant
- Major cost buckets
- Working capital snapshot
- Any existing KPI dashboards

If unavailable:
Provide whatever format exists (Excel / Tally export / PDF)

---

## 5. Operations Data

Folder: 03_Operations

Manufacturing:
- Production volumes
- Downtime logs
- Quality / rejection data
- Maintenance logs
- Shift data

Services:
- Delivery timelines
- Utilization metrics
- SLA performance
- Rework data

Logistics:
- On-time %
- Delay reasons
- Route data
- Fleet utilization

Solar / EPC:
- Project pipeline
- Installation timelines
- Commissioning delays
- Vendor performance
- Site-level cost data

---

## 6. Procurement & Vendor Data

Folder: 04_Vendors

- Vendor list
- Annual spend per vendor
- Top 20 vendor contracts (if possible)
- Procurement approval process description

---

## 7. Customer & Revenue Leakage Indicators

Folder: 05_Customers

- Customer churn data
- Complaint logs
- Credit note history
- Top 20 customer revenue list
- Sales funnel data (if applicable)

---

## 8. Compliance & Risk

Folder: 06_Compliance

- Audit observations (last 1–2 years)
- Incident reports
- CAPA logs
- Internal control documentation (if available)

---

## 9. Optional (Advanced Audit)

Folder: 07_Advanced

Only if available:

- Machine-level data exports
- API access (read-only)
- ERP database snapshot (read-only)
- Power BI / Tableau exports

---

## 10. Data Handling Guarantees

EraIn AI™ guarantees:

- Data used only for audit purposes
- No resale or third-party distribution
- Secure deletion upon request
- Structured access logging
- Minimal retention beyond engagement

---

## 11. What NOT To Send

- Personal employee bank details
- Unmasked Aadhaar / PAN data
- Unrelated legal disputes
- Password lists
- Source code access (unless explicitly agreed)

---

## 12. Final Pre-Submission Checklist

Before upload confirm:

[ ] Folder names match required structure  
[ ] Files labeled clearly  
[ ] No duplicate copies  
[ ] Sensitive data masked where possible  
[ ] NDA signed (if required)  
[ ] Internal approval obtained  

---

Once uploaded:

Email: intake@erainai.com  
Subject Line: CLIENTNAME – Audit Data Submitted – YYYYMMDD  

EraIn will confirm receipt within 24 business hours.
