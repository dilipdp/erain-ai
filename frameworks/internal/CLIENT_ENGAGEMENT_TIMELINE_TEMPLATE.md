

# EraIn AI — Client Engagement Timeline Template  
*(Universal Execution Flow: From First Conversation → Impact AI Rollout)*

---

# 1️⃣ Stage 0 — Pre‑Engagement (Internal Readiness)

**Objective:** Ensure EraIn is prepared before collecting any client data.

### Internal Checklist
- [ ] Universal Execution Core ready
- [ ] Industry Framework selected (Manufacturing / Logistics / Services / Solar / etc.)
- [ ] KPI Library aligned to sector
- [ ] Leakage Taxonomy aligned
- [ ] Execution Tracker Template prepared
- [ ] NDA template ready
- [ ] Data Intake Checklist ready

**Owner:** Engagement Lead  
**Output:** Green signal to initiate formal engagement

---

# 2️⃣ Stage 1 — Discovery & Qualification (Week 0)

**Objective:** Validate seriousness and fit before document exchange.

### Activities
- Executive call (45–60 mins)
- Understand:
  - Business size
  - Sites / plants / branches
  - ERP / Tally / Excel maturity
  - Leadership intent
- Identify:
  - Primary leakage hypothesis
  - Urgency level
  - Decision maker

### Decision Gate
- Is leadership serious?
- Is access realistic?
- Is ROI potential visible?

**Output:**
- Engagement Qualification Summary (1-page internal note)
- Go / No-Go decision

---

# 3️⃣ Stage 2 — NDA & Formal Intake Approval (Week 1)

**Objective:** Establish trust and legal clarity.

### Actions
- NDA shared
- NDA signed
- Data scope defined (minimal required first)
- Data access model defined:
  - Email-based document upload
  - Drive access
  - Shared folder
  - On-site review

**Output:**
- Signed NDA
- Approved Data Scope
- Data Intake Schedule

---

# 4️⃣ Stage 3 — Data Intake (Week 1–2)

**Objective:** Structured, controlled data collection.

### Intake Categories
- Financial (P&L, cost structure, working capital)
- Operational (throughput, downtime, utilization)
- Vendor / Procurement
- Sales / Revenue
- Compliance / Risk
- Organizational structure

### Rules
- Collect minimum viable data first
- Avoid ERP integration initially
- Start with exported reports (Excel/PDF)

**Output:**
- Data Completeness Score
- Intake Tracker Updated
- Risk Flags Noted

---

# 5️⃣ Stage 4 — EraIn Audit AI™ (Week 2)

**Objective:** Surface ranked value leaks.

### Deliverables
- Ranked leakage table
- Financial impact estimates
- Risk scoring
- 30/60/90 Roadmap
- Executive PDF

**Internal Artifacts**
- Leakage Mapping Sheet
- Root Cause Hypothesis Log
- Impact Estimation Model

**Client Output**
- Audit Summary Deck (PDF)
- Roadmap (Action-ready)

---

# 6️⃣ Stage 5 — Pro Audit™ (Optional Upgrade, Week 3–4)

**Objective:** Quantified, board-ready clarity.

### Adds
- Deep root-cause analysis
- Validation interviews
- On-site validation (if required)
- ₹/$ recovery estimates
- Owner-mapped execution plan

**Deliverables**
- 90-Day Execution Plan
- Accountability Matrix
- Governance Model
- Executive Alignment Call

---

# 7️⃣ Stage 6 — OpsMind™ Deployment (Month 2+)

**Objective:** Install operating cadence.

### Install
- KPI Dashboard (focused, not vanity)
- Weekly Decision Brief
- Anomaly Detection
- Execution Tracker
- Owner Review Cadence

### Governance Loop
- Weekly Ops Review
- Monthly Impact Review
- Quarterly Strategic Review

**Outcome**
- Reduced decision latency
- Reduced leakage recurrence
- Sustained execution discipline

---

# 8️⃣ Stage 7 — Impact AI™ Enterprise Rollout

**Objective:** Permanent intelligence layer.

### Includes
- ROI Attribution Engine
- Cross-functional visibility
- Decision memory archive
- Audit trail system
- Governance automation

**Outcome**
- Compounding performance
- Institutional intelligence
- Measurable long-term impact
