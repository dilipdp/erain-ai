

# EXECUTION CADENCE TEMPLATE
### EraIn Universal Execution Engine
Version 1.0
Status: Core Framework

---

## 1. Purpose

This template defines how execution is structured after audit findings are identified.

It ensures:
- Every finding has an owner
- Every action has a deadline
- Every initiative has checkpoints
- Every improvement is measurable
- Every result is attributable

This is the discipline layer that prevents “plans that don’t happen.”

---

## 2. Core Cadence Structure

EraIn execution operates in repeating cycles:

Truth → Decision → Assignment → Execution → Review → Proof

Each initiative must follow this loop.

---

## 3. Execution Object Structure

Every execution item must be documented as follows:

### Execution ID:
Unique identifier

### Problem Statement:
Clear description of the root cause

### Impact:
₹ / $ loss, risk exposure, operational delay, or qualitative impact

### Target Outcome:
Measurable improvement target

### Owner:
Single accountable person (not a team)

### Supporting Roles:
Contributors (if any)

### Start Date:
Defined start

### Deadline:
Hard completion date

### Milestones:
Checkpoint 1:
Checkpoint 2:
Checkpoint 3:

### KPI Impact:
Which KPIs will change

### Evidence Required:
What proof confirms completion

---

## 4. Weekly Cadence Template

Weekly Review Agenda (45–60 min)

1. Review last week commitments
2. Status of all active execution items
   - On track
   - Delayed
   - Blocked
3. Quantified movement in KPIs
4. Root-cause review for delays
5. Assign next week priorities
6. Close completed items with proof

Rule:
No meeting ends without:
- Updated owners
- Updated deadlines
- Updated measurable outcomes

---

## 5. Monthly Cadence Template

Monthly Executive Review (60–90 min)

1. KPI movement summary
2. Financial impact summary
3. Closed initiatives (with proof)
4. Delayed initiatives (with root-cause)
5. New initiatives (if required)
6. Risk signals

Outputs:
- ROI attribution update
- Execution health score
- Risk heatmap update

---

## 6. Escalation Model

If an item is delayed:

Week 1 Delay:
→ Owner explanation + new date

Week 2 Delay:
→ Root-cause analysis required

Week 3 Delay:
→ Executive escalation

No silent delays allowed.

---

## 7. Execution Health Score

Each cycle receives a score based on:

- % initiatives completed on time
- % initiatives with measurable proof
- KPI movement trend
- Delay recurrence rate

This becomes a leadership confidence indicator.

---

## 8. What This Prevents

- Ownership ambiguity
- Hidden delays
- AI reports without execution
- Strategy without follow-through
- “We tried” culture

---

## 9. Minimum Standards

No initiative may start without:
- Defined owner
- Defined deadline
- Defined measurable outcome

No initiative may close without:
- Evidence
- KPI update
- Financial attribution (if applicable)

---

## 10. Implementation Notes

This cadence template is industry-agnostic.

It applies to:
- Manufacturing plants
- Solar EPC
- Logistics operations
- Service organizations
- Retail networks
- Multi-site enterprises
- Regulated industries
- Technology companies

Execution discipline is universal.
