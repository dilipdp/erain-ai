# 4. WEEKLY EXECUTION CADENCE (NON-NEGOTIABLE)

## Weekly Review Structure
Duration: 60–90 minutes
Attendees: Sponsor + Execution Owner + Functional Leads + EraIn

Agenda:
1. Review last week commitments
2. KPI delta vs target
3. New risks detected
4. Root cause updates
5. Next week commitments (owner + deadline)

All commitments must be documented.
No verbal-only agreements.

# 9. ESCALATION RULES

Escalate to Sponsor if:
- KPI Red for 2 weeks
- Owner misses 2 commitments
- Financial impact deviates >15% from estimate
- Compliance / regulatory risk emerges

Escalation must be documented.

---

# 10. CLOSURE CRITERIA

An engagement phase is considered complete only when:

- Top 3 leaks show measurable reduction
- Owners are internally accountable
- KPI monitoring continues without EraIn push
- Financial impact is documented
- Governance is installed

If these are not true, the phase is NOT complete.
