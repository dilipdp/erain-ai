# 1. ROI STRUCTURE (UNIVERSAL MODEL)

Every quantified opportunity must pass through 5 layers:

1️⃣ Baseline Definition  
2️⃣ Leakage Quantification  
3️⃣ Action Mapping  
4️⃣ Financial Conversion  
5️⃣ Attribution Validation  

Skipping any layer invalidates ROI.

---

# 2. BASELINE DEFINITION

Baseline must include:

• Time period  
• Metric definition  
• Data source  
• Owner validation  
• Variance tolerance  

Example:
Downtime = 120 hours/month (avg last 6 months)  
Source = ERP log  
Owner = Plant Head  

No baseline → no ROI.

---

# 3. LEAKAGE QUANTIFICATION

1. Time Leakage  
2. Cost Leakage  
3. Revenue Leakage  
4. Quality Leakage  
5. Decision Leakage  
6. Ownership Leakage  
7. System Leakage  

Each leakage must define:

• Frequency  
• Magnitude  
• Scope  
• Financial sensitivity  

---

# 4. FINANCIAL CONVERSION LOGIC

All operational metrics must convert into ₹ / $ impact.

## 4.1 Time → Money

Lost Output = Downtime Hours × Output per Hour  
Financial Loss = Lost Output × Contribution Margin  

## 4.2 Quality → Money

Scrap Cost = Scrap Units × Cost per Unit  
Rework Cost = Rework Hours × Labor Rate  

## 4.3 Revenue → Money

Revenue Recovery = Churn Reduction × Avg Revenue per Client  
Missed Billing Recovery = Unbilled Units × Billing Rate  

## 4.4 Working Capital → Money

Cash Freed = Working Capital Reduction  
Financial Benefit = Cash Freed × Cost of Capital  

## 4.5 Risk → Money

Expected Loss = Probability × Financial Exposure  
Risk Reduction Value = (Old Probability − New Probability) × Exposure

ROI % = (Recovered Value − EraIn Fee) / EraIn Fee × 100

Payback Period = EraIn Fee / Monthly Recovered Value

IRR may be used for larger projects (>6 months).
