# 1. PURPOSE

The Impact Ledger is the official record of value created through execution.

It converts:
- Diagnosed leakage  
- Approved execution  
- Measured change  

Into:

> Verified financial impact  
> Attributed ownership  
> Audit-ready proof  

This ledger is non-negotiable.  
If impact is not recorded here, it does not count.
