# 3. UNIVERSAL FINANCIAL IMPACT FORMULA

Financial Impact = (Leak Size × Frequency × Cost Multiplier) – Implementation Cost

Where:

Leak Size = measurable inefficiency (hours, %, units, downtime, etc.)
Frequency = how often it occurs
Cost Multiplier = ₹ or $ per unit
Implementation Cost = cost of fixing
