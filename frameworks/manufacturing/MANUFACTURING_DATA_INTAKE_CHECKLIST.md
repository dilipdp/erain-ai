

# MANUFACTURING DATA INTAKE CHECKLIST
Version: 1.0  
Purpose: Define strict data collection standards before Manufacturing Audit begins  
Classification: Internal – Governance Critical  

---

# CORE RULE

We do NOT begin OEE or ROI modeling without structured, validated data.

Incomplete data = distorted throughput logic  
Distorted throughput logic = overstated ROI  
Overstated ROI = damaged trust  

If mandatory inputs are missing → pause engagement.

---

# 1 — PLANT OVERVIEW (MANDATORY)

Client must provide:

[ ] Plant name + location  
[ ] Number of lines / machines  
[ ] Shift structure (hours per shift, shifts per day)  
[ ] Working days per month  
[ ] Installed rated capacity (units/hour)  
[ ] Current SKU mix overview  
[ ] Bill of Materials (high-level, for margin validation)  

Validation:

[ ] Capacity figures consistent across documents  
[ ] Shift structure confirmed by operations head  
[ ] SKU mix stable or seasonal? (documented)

Reject analysis if:
• Capacity unclear  
• Shift structure inconsistent  

---

# 2 — PRODUCTION DATA (MINIMUM 6–12 MONTHS)

Required:

[ ] Monthly production volume (units)  
[ ] Line-wise production (preferred)  
[ ] Planned production hours  
[ ] Actual running hours  
[ ] Machine utilization reports  

Validation:

[ ] Identify idle capacity periods  
[ ] Identify demand-limited months  
[ ] Check abnormal volume spikes  

If less than 6 months → mark as limited-confidence audit.

---

# 3 — OEE COMPONENT DATA

## 3.1 Availability

Required:

[ ] Planned production time  
[ ] Downtime hours (categorized)  
[ ] Breakdown logs  
[ ] Maintenance logs  

Validation:

[ ] Downtime categorized (breakdown / planned / minor stops)  
[ ] Confirm repeat failure patterns  
[ ] Cross-check downtime vs maintenance logs  

---

## 3.2 Performance

Required:

[ ] Ideal cycle time  
[ ] Actual cycle time  
[ ] Output per hour  

Validation:

[ ] Confirm ideal cycle time source  
[ ] Confirm no SKU distortion  
[ ] Identify speed losses vs demand constraints  

---

## 3.3 Quality

Required:

[ ] Scrap quantity (units)  
[ ] Rework quantity  
[ ] Scrap reason categorization  
[ ] Warranty / field return data (if applicable)  

Validation:

[ ] Scrap tied to production volume  
[ ] Avoid double counting scrap + rework  
[ ] Confirm financial valuation method  

---

# 4 — FINANCIAL DATA (MANDATORY FOR ROI)

Required:

[ ] Contribution margin per unit (validated by finance)  
[ ] Revenue per unit (for reference only)  
[ ] Direct material cost per unit  
[ ] Variable labor cost per unit  
[ ] Major overhead structure (high-level)  

Validation:

[ ] Contribution margin approved by CFO / finance head  
[ ] Margin not inflated  
[ ] Clear separation of fixed vs variable cost  

Never use revenue for throughput monetization.

Always use contribution margin.

---

# 5 — INVENTORY & WORKING CAPITAL DATA

Required:

[ ] Raw material inventory levels  
[ ] WIP levels  
[ ] Finished goods inventory  
[ ] Inventory carrying cost %  

Validation:

[ ] Identify slow-moving stock  
[ ] Identify safety stock logic  
[ ] Confirm carrying cost basis  

Cash flow impact must be separated from margin impact.

---

# 6 — CHANGEOVER DATA

Required:

[ ] Changeover duration per SKU  
[ ] Changeover frequency  
[ ] SKU sequencing logic  

Validation:

[ ] Identify avoidable changeovers  
[ ] Identify clustering opportunity  
[ ] Confirm if demand-driven  

Do not monetize strategic SKU diversification.

---

# 7 — MAINTENANCE & BREAKDOWN COSTS

Required:

[ ] Breakdown frequency  
[ ] Average repair cost  
[ ] Spare consumption cost  
[ ] Preventive maintenance schedule  

Validation:

[ ] Identify repeat-failure machines  
[ ] Confirm reactive vs preventive ratio  
[ ] Identify spare overstock risk  

---

# 8 — BOTTLENECK IDENTIFICATION

Required:

[ ] Line balancing study (if available)  
[ ] Throughput per machine  
[ ] Constraint identification (operations validated)  

Validation:

[ ] Confirm true constraint  
[ ] Confirm revenue limited by bottleneck  
[ ] Do not monetize non-constraint improvements  

---

# 9 — DATA FORMAT REQUIREMENTS

Accepted:

• ERP export (Excel / CSV)  
• Machine logs (structured)  
• Maintenance system export  

Not acceptable:

• Screenshots  
• Manual typed summaries  
• WhatsApp messages  

All data must be source-exported.

---

# 10 — DATA QUALITY GRADING

After intake, assign grade:

A — Complete + consistent  
B — Minor gaps  
C — Partial data  
D — Insufficient for ROI modeling  

If C or D:
Limit ROI projection and clearly disclose assumptions.

---

# 11 — CONFIDENTIALITY PROTOCOL

Before intake:

[ ] NDA signed  
[ ] Secure folder created  
[ ] Access restricted  
[ ] File naming structure applied  
[ ] Version control enabled  

Never mix client data.

---

# 12 — INTAKE COMPLETION DECLARATION

Before modeling begins:

[ ] OEE inputs complete  
[ ] Margin validated  
[ ] Demand constraint assessed  
[ ] Double-count risk assessed  
[ ] Conservative assumptions defined  

If unchecked → delay analysis.

---

# DISCIPLINE RULE

Manufacturing ROI can look massive.

Do not exaggerate.

If demand is capped → reduce monetization.  
If margin unclear → use conservative value.  
If constraint not confirmed → pause claim.

Precision > optimism.  
Structure > speed.

---

This checklist protects:

• Financial credibility  
• OEE integrity  
• CFO defensibility  
• Execution realism  
• Brand authority  

Manufacturing audit begins only after intake control is established.
