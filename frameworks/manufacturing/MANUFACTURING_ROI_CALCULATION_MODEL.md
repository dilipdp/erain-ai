
# MANUFACTURING ROI CALCULATION MODEL
Version: 1.0  
Purpose: Standardize financial defensibility of EraIn Manufacturing engagements  
Classification: Internal – Financial Governance Critical  

---

# CORE PRINCIPLE

ROI must be:

✔ Quantifiable  
✔ Reproducible  
✔ Finance-validated  
✔ Conservative-first  
✔ Traceable to baseline  

If ROI cannot be defended in front of a CFO, it cannot be presented.

---

# 1 — ROI STRUCTURE

Total Recoverable Value (TRV) =
Σ (Leakage Impact × Recoverable % × Time Window)

Net Recovered Value (NRV) =
Validated Financial Gain – Cost of Engagement

ROI Multiple =
NRV / Engagement Cost

Payback Period =
Engagement Cost / Monthly Validated Gain

---

# 2 — LEAKAGE CATEGORY MODELS

---

## A. DOWNTIME MODEL

Contribution per Hour =
(Sales per Hour – Variable Cost per Hour)

Downtime Loss =
Contribution per Hour × Downtime Gap Hours

Recoverable Value =
Downtime Loss × Realistic Recovery %

Recommended Recovery % Ranges:
• Conservative: 30%
• Base: 50%
• Aggressive: 70%

Never assume 100% recovery.

---

## B. SCRAP / REWORK MODEL

Scrap Gap % =
(Current Scrap % – Benchmark Scrap %)

Scrap Financial Impact =
Annual Production Value × Scrap Gap %

Recoverable Value =
Scrap Financial Impact × Recovery %

Recovery Range:
• Conservative: 25%
• Base: 40%
• Aggressive: 60%

---

## C. OEE CAPACITY MODEL

OEE Gap =
(Benchmark OEE – Current OEE)

Capacity Value =
Installed Capacity Revenue × Contribution Margin

Capacity Leakage =
OEE Gap × Capacity Value

Recoverable (Year 1):
Capacity Leakage × 40–60%

Important:
Capacity value must be validated against demand.
No demand → no capacity monetization.

---

## D. INVENTORY WORKING CAPITAL MODEL

Excess Days =
(Current Inventory Days – Benchmark Days)

Working Capital Locked =
Excess Days × Daily COGS

Cash Unlock Potential ≠ Profit

Report separately:
• P&L impact
• Cash-flow impact

Never mix both.

---

## E. MAINTENANCE REACTIVITY MODEL

Reactive Gap =
(Current Reactive % – Target %)

Maintenance Cost Impact =
Total Maintenance Spend × Reactive Gap %

Recoverable Value =
Maintenance Cost Impact × 30–50%

---

# 3 — CONSERVATIVE FIRST RULE

When presenting externally:

Always use Conservative Case.

If Conservative ROI < 3x → reassess engagement structure.

EraIn should target:
5x–10x ROI in base case.

---

# 4 — ROI VALIDATION PROTOCOL

Before reporting any ROI:

[ ] Baseline documented  
[ ] Data source verified  
[ ] Formula cross-checked  
[ ] Finance approval obtained  
[ ] Improvement period defined  
[ ] No double counting  

Double counting examples:
• Counting OEE + Downtime for same impact  
• Counting scrap + rework twice  
• Counting capacity without demand  

If overlap detected → adjust downward.

---

# 5 — TIME WINDOW STRUCTURE

Short Term:
30–90 days

Mid Term:
6 months

Full Year:
12 months

All ROI must specify time window.

No undefined projections allowed.

---

# 6 — COST OF ENGAGEMENT STRUCTURE

Engagement Cost must include:

• Audit cost  
• Implementation advisory  
• Tracking support  
• Governance sessions  
• Travel (if applicable)  
• Internal team allocation  

Hidden cost distortions reduce credibility.

---

# 7 — CFO DEFENSE CHECKLIST

Before executive presentation, confirm:

[ ] All numbers reconciled to P&L  
[ ] Contribution margin validated  
[ ] Assumptions explicitly stated  
[ ] Conservative case shown first  
[ ] Recovery % justified  
[ ] No optimistic stacking  
[ ] Risks disclosed  

If challenged:
Be transparent.
Never inflate.

Credibility compounds faster than revenue.

---

Slide 4 – Conservative Case
