

# MANUFACTURING ROI MODEL
Version: 1.0  
Purpose: Standardize financial defensibility of EraIn Manufacturing engagements  
Classification: Internal – Financial Governance Critical  

---

# CORE PRINCIPLE

Manufacturing ROI must be:

✔ OEE-grounded  
✔ Capacity-realistic  
✔ Double-count protected  
✔ Conservative-first  
✔ CFO-reconcilable  

If downtime is not monetized through throughput logic → it is not defensible.  
If scrap savings are not margin-adjusted → it is overstated.

---

# 1 — ROI STRUCTURE

Total Recoverable Value (TRV) =
Σ (Controllable Loss × Recovery % × Time Window)

Net Recovered Value (NRV) =
Validated Financial Gain – Engagement Cost

ROI Multiple =
NRV / Engagement Cost

Payback Period =
Engagement Cost / Monthly Validated Gain

---

# 2 — OEE-BASED LOSS MONETIZATION

OEE = Availability × Performance × Quality

We monetize only controllable gaps.

## 2.1 Availability (Downtime Loss)

Availability Loss =
Planned Production Time – Actual Running Time

Throughput Loss (Units) =
Downtime Hours × Ideal Run Rate

Financial Impact =
Throughput Loss × Contribution Margin per Unit

Important:
Use contribution margin, NOT revenue.

---

## 2.2 Performance Loss (Speed Loss)

Performance Gap =
Ideal Cycle Time – Actual Cycle Time

Lost Output =
(Running Time × Ideal Rate) – Actual Output

Financial Impact =
Lost Output × Contribution Margin

Exclude:
Demand-limited production periods.

---

## 2.3 Quality Loss (Scrap + Rework)

Scrap Loss =
Scrap Units × Contribution Margin

Rework Loss =
(Rework Labor + Material + Delay Cost)

If scrap already reflected in OEE quality → do not double count.

---

# 3 — CAPACITY UNLOCK MODEL

Hidden Capacity =
(OEE Benchmark – Actual OEE) × Installed Capacity

Unlocked Revenue Potential =
Hidden Capacity × Realistic Demand Absorption %

Financial Impact =
Unlocked Volume × Contribution Margin

Never assume 100% demand absorption.

Use:
• Conservative: 40%
• Base: 60%
• Aggressive: 75%

---

# 4 — CHANGEOVER OPTIMIZATION MODEL

Changeover Loss =
Average Changeover Duration × Frequency

Recovered Time =
Changeover Reduction × Frequency

Recovered Output =
Recovered Time × Ideal Rate

Financial Impact =
Recovered Output × Contribution Margin

Exclude:
Strategic SKU mix shifts.

---

# 5 — WORKING CAPITAL IMPACT

Inventory Reduction Impact =
Excess Inventory × Carrying Cost %

Cash Flow Improvement must be separated from P&L impact.

Never mix:
• Margin gains
• Cash release
• Cost avoidance

Report separately.

---

# 6 — MAINTENANCE MATURITY MODEL

Reactive Maintenance Cost =
Breakdown Frequency × Avg Repair Cost

Preventive Shift Impact =
Reduction in Breakdown Frequency × Cost

Include:
• Spare holding optimization
• Downtime avoidance value

Do not assume zero breakdown future state.

---

# 7 — BOTTLENECK IDENTIFICATION RULE

System Throughput = Bottleneck Throughput

Improving non-bottleneck areas:
Does NOT increase plant revenue.

Only monetize improvements at constraint.

---

# 8 — DOUBLE COUNT PROTECTION

Before reporting:

[ ] Downtime not counted again under OEE performance  
[ ] Scrap not double counted  
[ ] Capacity unlock not double counted with downtime  
[ ] Changeover not overlapping downtime  
[ ] Maintenance not overlapping availability  

If overlap detected → reduce claim.

Credibility > headline number.

---

# 9 — FINANCIAL DEFENSE STRUCTURE (CFO CHECK)

Before presenting:

[ ] Contribution margin validated with finance  
[ ] Demand constraint assessed  
[ ] Working capital separated  
[ ] Assumptions documented  
[ ] Conservative case shown first  
[ ] Sensitivity analysis included  

If any unchecked → do not present.

---

# 10 — CONSERVATIVE PRESENTATION RULE

Target realistic ROI:
3x–8x for manufacturing (healthy range)

If projection >12x:
Stress-test assumptions.

Board-level trust > inflated numbers.

---

# 11 — ROI MATURITY SCALE

Level 1 – Estimated  
Level 2 – OEE-grounded  
Level 3 – Finance reconciled  
Level 4 – Post-implementation validated  
Level 5 – Institutionalized monitoring  

EraIn must reach Level 4 before publishing case study.

---

# INTERNAL DISCIPLINE RULE

If recovery seems easy:
Recalculate.

If margin seems inflated:
Reduce.

If capacity unlock assumes perfect demand:
Adjust.

Overstatement destroys authority.
Precision compounds reputation.

---

This model ensures:

• OEE-grounded credibility  
• Contribution-margin realism  
• Bottleneck discipline  
• Cash vs P&L separation  
• Zero double counting  

Manufacturing ROI must be throughput-backed and finance-proven.
