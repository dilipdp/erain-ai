

# UNIVERSAL_DATA_REQUEST_TEMPLATE — EraIn AI

> **Status:** Draft v1 (Ready to use)
> 
> **Purpose:** Collect only the minimum data required to run an EraIn Audit / Pro Audit safely, quickly, and consistently — across **any industry**.
> 
> **Principles:** Minimal data • Privacy-first • Least privilege • Incremental access • Redaction-ready • Audit-traceable

---

## 0) Before you share anything

### What we need from you (1 minute)
- Confirm your **industry** and **business model** (B2B/B2C/mixed)
- Confirm your **time window** for audit (recommended: **last 3 months**; optional: 6–12 months)
- Confirm who will be the **single point of contact (SPOC)** for clarification

### What NOT to share yet
Until EraIn confirms readiness + access scope, **do not share**:
- Personal IDs (Aadhaar/PAN), bank logins, OTPs, passwords
- Customer PII (names, phone numbers, addresses) unless explicitly requested and approved
- Employee personal data (salary slips, IDs) unless explicitly requested and approved
- Any data governed by NDA/contract that requires formal permission first

### Our preferred approach (safer)
- Share **aggregated exports** and **masked datasets** first.
- If deeper investigation is required, we request a **second wave**.

## 1) Data Request — Wave 1 (Minimum viable audit)

> **Goal:** Produce ranked findings + leakage map + 30/60/90 plan with owners and checkpoints.

### 1.1 Company snapshot (required)
Provide a 1–2 page PDF or simple doc (or answer in email):
- Legal entity name, locations/sites, headcount (approx)
- Products/services (top 5), top customer segments
- Org structure (simple) + key owners (Ops, Finance, Sales)
- Current tools: Excel/Tally/ERP/CRM/WMS/anything else

### 1.2 Financial & profitability (required — minimal)
Any one of the following formats is okay (PDF export or Excel):
- **P&L** (monthly) for the selected time window
- **Trial balance** (monthly) OR basic expense ledger summary
- **Sales register / invoices summary** (monthly totals)

**If available (nice-to-have):**
- Cost center wise expenses
- Product-wise or service-line gross margin

### 1.3 Operations & delivery (required — choose what applies)
Pick the section that matches your business. Provide exports if available.

**Manufacturing / Industrial / Plants**
- Production output summary (daily/weekly)
- Downtime / breakdown log (if any)
- Rejection/rework summary
- Maintenance schedule + major incidents list

**Services / Projects / EPC / Agency**
- Project list with status, deadlines, delays (simple sheet)
- Timesheets/utilization summary (if any)
- Rework/escalations/issues list

**Logistics / Supply chain / Warehousing**
- Shipment/dispatch summary (on-time vs delayed)
- Exceptions list (damage, shortage, returns)
- Fleet/route summary (if any)

**Retail / Distribution / D2C**
- Order summary (placed/fulfilled/cancelled)
- Returns/refunds summary
- Stock-out / overstock notes (if tracked)

**Solar / Energy / Renewables**
- Project pipeline + stage status (survey/design/EPC/commissioning)
- Procurement tracker (modules/inverters/structure)
- Site-wise delays + reasons
- O&M incidents list (if applicable)

### 1.4 Sales, customers, service (required — minimal)
- Lead funnel summary (monthly): leads → qualified → won → lost
- Top 10 reasons for loss / churn (even if qualitative)
- Support tickets summary (count by category) OR issue spreadsheet

### 1.5 Inventory & procurement (optional but powerful)
- Top 20 vendors + purchase summary
- Inventory snapshot (opening/closing) if applicable
- Stock movement summary (in/out) if applicable

### 1.6 People & execution cadence (required — lightweight)
- Current meeting cadence (weekly ops, finance review, sales review)
- Any OKRs/KPIs currently tracked
- Escalation path (who owns what when something breaks)

## 4) Privacy, security, and handling

### Minimum exposure
- We request **only what is required**.
- We start with **aggregates**; drill down only when proven necessary.

### Redaction rules (default)
Before sharing, please mask:
- Customer phone numbers/emails → keep last 2–4 digits only
- Names → initials or hashed ID
- Bank details → remove entirely

If you can’t redact easily, send as-is and we will:
- Confirm safe handling
- Provide a redaction template

### Where to share
EraIn will confirm one of:
- Secure upload link (preferred)
- Encrypted archive (zip) with separate password channel
