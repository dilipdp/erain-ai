

# EraIn AI — Client Data Request Checklist
Version: 1.0  
Applies To: All Industries (Manufacturing, Services, Logistics, Retail, Solar, etc.)  
Purpose: Structured, minimum-necessary, audit-first data collection  

---

## ⚠️ Before Data Collection (Mandatory)

☐ NDA Signed  
☐ Data Usage Scope Defined (Audit Only / Pro Audit / OpsMind)  
☐ Access Method Confirmed (Email / Drive / Onsite / Read-only ERP)  
☐ Data Retention Policy Explained  
☐ Client Approval for Sensitive Data Categories  

EraIn Principle:  
We collect only what is required to establish **verified operational reality**.  
No raw data hoarding. No unnecessary access.
