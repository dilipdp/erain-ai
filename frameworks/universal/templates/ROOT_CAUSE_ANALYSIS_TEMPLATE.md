# 🚨 ROOT CAUSE RULES (NON-NEGOTIABLE)

1. Never stop at the first “why”.
2. Never blame individuals without system analysis.
3. If it is not measurable, it is not fixed.
4. If there is no owner, it will fail again.
5. If impact is not quantified, leadership won’t prioritize it.

---

# ERAIN STANDARD

Every RCA must end with:
- Quantified financial impact
- Named owner
- Measurable KPI
- Review cadence
- Prevention mechanism

No RCA is considered complete without these five.
