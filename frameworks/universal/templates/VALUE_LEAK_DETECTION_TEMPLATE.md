# PURPOSE

This template is used to systematically identify hidden value leaks across any industry.

Value leaks exist where:
- Money is lost silently
- Time is wasted repeatedly
- Decisions are delayed or made blindly
- Ownership is unclear
- Rework and inefficiencies compound

This template must be used BEFORE deep data collection.
